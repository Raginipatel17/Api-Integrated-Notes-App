## 📝 Notes Application

A secure notes and task management web application where users can **register or log in** to access their personal notes.

Users can:
- ➕ Add notes or tasks  
- ⭐ Set task priority (high / medium / low)  
- 🔐 Manage notes securely with user authentication  

The application also integrates **Weather API** and **Travel API** in the background to enhance functionality and simulate real-world API usage.

This project focuses on **authentication**, **API integration**, and **building a practical full-stack application**.
